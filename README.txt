MR. BROWN RESTAURANT PRO ONLINE BILLING
Features: mobile/desktop shared database, menu management, new bills, bill history/search, dashboard sales, average bill, cash/UPI/card, printable receipt.

RUN: install Node.js 18+, then npm install, then npm start. Open http://localhost:3000.

ONLINE: deploy the folder to a Node.js host with persistent storage. Use the same HTTPS URL on phone and computer. Add authentication/cloud backups before production use.
